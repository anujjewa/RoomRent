# Room Rent Web App

A React-based web application where users can browse, filter, and manage rental rooms.

## Features

- Browse rooms with search, filter, and sorting
- View detailed room information with image gallery
- Add, edit, and delete room listings (Owner role)
- Favorites (wishlist) functionality
- Role-based UI (Owner vs Renter)
- Data persistence using localStorage

## Tech Stack

- React (Vite)
- JavaScript
- CSS
- React Router

## Getting Started

```bash
npm install
npm run dev
